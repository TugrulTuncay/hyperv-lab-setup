# 🖥️ Hyper-V Lab Setup & Active Directory Simulation

Bu projede Microsoft Hyper-V kullanarak sanal bir IT laboratuvarı oluşturulmuş ve temel sistem yönetimi ile ağ yapılandırmaları uygulanmıştır.

## 🎯 Proje Amacı

* Sanallaştırma teknolojilerini öğrenmek
* Windows Server ortamı kurmak
* Active Directory mantığını kavramak
* Sistemler arası ağ iletişimini test etmek

---

## 🧰 Kullanılan Teknolojiler

* Microsoft Hyper-V
* Windows 10 Pro
* Windows Server 2022
* Active Directory Domain Services (AD DS)

---

## ⚙️ Yapılan İşlemler

* Hyper-V üzerinde sanal makineler oluşturuldu
* Windows 10 ve Windows Server kurulumu yapıldı
* Sanal makineler arasında IP yapılandırması yapıldı
* `ping` komutu ile makineler arası iletişim test edildi
* Windows Defender Firewall ayarları düzenlendi
* Active Directory (AD DS) kuruldu
* Domain Controller yapılandırıldı
